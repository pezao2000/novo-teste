# Genuína Lindoya — Site (versão de testes)

Versão de testes/iteração da landing page da **Genuína Lindoya**, marca de água mineral natural com 61 anos de tradição.

🔗 **Online:** https://pezao2000.github.io/novo-teste/

## O que tem nesta versão

Mesmo conteúdo da landing principal ([genuina-lindoya-landing](https://github.com/pezao2000/genuina-lindoya-landing)), com ajustes adicionais:

- Correção do rodapé e da chamada final, que ficavam ilegíveis no **modo escuro**

## Seções

- Hero — "A água que nasce na fonte."
- Linhas de produto: Água Mineral Natural, Lindoya Fruta, Fruthy e Linha Light
- Seletor de sabores, seis motivos, kits, perguntas frequentes e chamada final

## Tecnologia

- Página única em **HTML + CSS + JavaScript puro** (`index.html`), sem build
- Tema claro/escuro automático (`prefers-color-scheme`)
- Publicado via **GitHub Pages**

## Como rodar

Abra o `index.html` no navegador.
